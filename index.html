How to Use This Activity

  1. Pick up the round stock piece: click or press Enter/Space when it is focused.
  2. Drag (or use Arrow keys while in drag mode) to place it into the drop zone.
  3. Adjust the caliper using the left/right arrow buttons or keyboard arrow keys.
  4. When positioned, enter the outside diameter to three decimals (e.g., 0.858).
  5. The input auto-submits when correct. Use Play Again to practice again.

Accessibility Features

  • Keyboard operable drag (Enter/Space to pick up, arrows to move, Enter to drop, Escape to cancel).
  • Screen reader announcements via polite status region and success confirmations.
  • Reduced motion support (prefers-reduced-motion disables pulsing animations).
  • High contrast text and focus outlines for interactive elements.
  • Structured helper text for input (format guidance) and throttled feedback while typing.
  • Persistent instructions and input region state for predictable navigation.
